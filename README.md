# DummyJSON API Tests

Тестовое задание: API-проверки для [DummyJSON](https://dummyjson.com).

---

## Об опыте

| Вид тестирования | Опыт |
|------------------|------|
| Ручное тестирование | Есть — 3+ года, функциональное, регрессионное, UX/UI, мобильные и веб-приложения (Яндекс Крауд) |
| Нагрузочное тестирование | Есть — JMeter, курс «Инженер по нагрузочному тестированию» (Brainup Academy, 2026) |
| Тестирование безопасности | Базовый уровень — проверка авторизации, работа с токенами, негативные сценарии |
